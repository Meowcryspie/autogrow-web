# Autogrow Web Architecture & Design Directives

## Design Standards & Anti-AI Policy
All user interface development in this repository must strictly follow the rules laid out in:
- [DESIGN_RULEBOOK.md](file:///c:/Projects/autogrow-web/DESIGN_RULEBOOK.md)
- [.agent/rules/anti-ai-design-rules.md](file:///c:/Projects/autogrow-web/.agent/rules/anti-ai-design-rules.md)

### Key Directives:
1. **Material Tactility**: Anodized titanium, matte carbon surfaces, and 1px mechanical hairline rules instead of glowing neon borders or generic gradients.
2. **Editorial Asymmetry**: Never use 3-column repetitive icon cards. Use split screens, CAD schematics, and technical spec tables.
3. **Engineering Authority**: Real CEA metrics (EC, pH, VPD, PPFD, VWC%), terminal pinouts, and zero marketing fluff.
